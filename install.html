Install Mary on your computer

After installation, Mary runs in your browser in one of these ways:

  1. Directly from thelady/music.html (very restricted: local audio files only).
  2. From a local web server of your choice:
    1. based on Python (mary.py, the default in these steps),
    2. the PHP built-in web server (php -S),
    3. or any server you personally possess.
  3. From a non-profit public HTML server based on surge.sh (you can upload the App folders to any web server at your own risk).

In every case you need git (to download the app) and a web server (the steps below guide you with the Python or PHP built-in servers). Follow the steps for your system. PHP and Docker are not required (Docker or Podman is, however, highly recommended). Having problems with the install process? Ask an AI assistant to guide you (ChatGPT, Google Gemini, Microsoft Copilot, etc.). Tell it your operating system, the step you are on and the exact error message.

Easiest way (no git, Python or PHP): download the zip for your system from the Releases page (Mary-windows.zip, Mary-macos.zip or Mary-linux.zip), unzip it and run mary.exe (Windows) or ./mary (macOS/Linux). Windows or macOS may warn that the program is unsigned: choose "More info → Run anyway" (Windows) or right-click → Open (macOS). Prefer the full guided install? Use the steps below.

The installer guides you step by step: git, the app download, publishing your own copy, Python, and the first run. Your progress is saved in this browser (IndexedDB), so you can close the page and continue later.

.surge.sh
  1. Check for git. Open Command Prompt (Windows key, type cmd) and run:
    git --version
    If it prints a version, go to step 3. Otherwise continue with step 2.
  2. Install git if needed:
    winget install Git.Git
    or download it from git-scm.com. Then close and reopen Command Prompt.
  3. Download the app (creates the folder {{DIR}}):
    git clone {{URL}}
    cd {{DIR}}
    To get later updates, run git pull inside that folder.
    At this step you can already use thelady/music.html in your browser, but only to play local mp3, mp4 and ogg audio files from your computer, with the Stop and Load buttons. To use the full app, continue with the next steps.
  4. Check for Node.js (the publishing tool, surge, needs it; Python is not needed for this). Run in Command Prompt:
    node --version
    If it prints a version number, go to step 6.
  5. Install Node.js if needed:
    winget install OpenJS.NodeJS.LTS
    or download the installer from nodejs.org. Then close and reopen Command Prompt and return to the folder with cd {{DIR}}.
  6. Publish your own copy at the address you chose above. Make sure you are in the app folder (the listing must show index.html):
    dir index.html
    Then publish it:
    npx surge . {{SITE}}.surge.sh
    The first time, surge asks for your email and a password. That creates your free account, and nothing is typed visibly in the password field. When it finishes, open https://{{SITE}}.surge.sh in your browser.
    Your published site works without Python. The steps below are only for running the local server on this computer.
  7. Check for Python.
    python --version
    It must print Python 3.8 or higher. If typing python opens the Microsoft Store, Python is not installed.
  8. Install Python if needed:
    winget install Python.Python.3.12
    or download it from python.org and tick "Add python.exe to PATH". Then close and reopen Command Prompt and re-enter the folder with cd {{DIR}}.
  9. Start Mary (from inside the folder):
    python mary.py
    Option B, PHP instead of Python: if you already have PHP, run php -S localhost:8000 in the app folder and open http://localhost:8000/thelady/music.html. PHP also runs tace-fetch.php for remote playlists.

Troubleshooting

node or npx is "not found" / "not recognized"

Close and reopen the terminal after installing Node.js. If it still fails, reinstall from nodejs.org.

Windows: PowerShell says running scripts is disabled (npx)

Use Command Prompt (cmd) instead of PowerShell.

Linux: npx fails with EACCES (permission denied)

Don't use sudo with npx. Fix the npm folder permissions or install Node.js with nvm.

surge says the domain is not available or you have no permission

Someone else already owns that name. Choose another address in the box at the top and run the publish command again.

Nothing appears when I type my surge password

That is normal: the password is hidden while you type. Type it and press Enter.

git or python is "not recognized" / "command not found" right after installing Close the terminal and open a new one. A terminal opened before the installation doesn't see the new program.
Windows: python opens the Microsoft Store Python isn't installed yet. Install it (step 8), then open a new Command Prompt. You can also try the Python launcher: py --version and py mary.py. If the Store still opens, turn off Settings → Apps → Advanced app settings → App execution aliases for "python.exe".
Windows: winget is not recognized Older Windows 10 versions don't have it. Download the installers instead: git and Python (tick "Add python.exe to PATH").
Linux/macOS: python doesn't exist Use python3. On Debian/Ubuntu, sudo apt update before installing can fix "package not found".
git clone fails
  • "destination path already exists": you already downloaded it. Run cd into the folder and git pull to update.
  • "repository not found" or 404: check the address you copied, and that you are online.
  • Behind a company proxy or firewall: ask your administrator, or download the ZIP from the repository page on GitHub instead of using git.
cd says the folder doesn't exist Run cd from the place where you ran git clone, or use the full path to the folder (the one that contains mary.py and thelady).
mary.py says "Cannot find thelady/music.html" or "can't open file" You are in the wrong folder. List it with dir (Windows) or ls (Linux/macOS): you must see mary.py and thelady.
"Python 3.8 or newer is required" Your Python is too old. Install a newer version (step 8) and run the version check again.
"Port 8080 is busy" Another program uses that port. Start with another one, for example python mary.py --port 9000 (python3 on Linux/macOS), then open http://localhost:9000/thelady/music.html.
The browser didn't open by itself Open http://localhost:8080/thelady/music.html yourself while mary.py is still running.
Windows asks to allow Python through the firewall Mary only listens on your own computer (127.0.0.1), so no network access is needed. You can click Cancel.
A remote playlist (?source=https://...) doesn't load Check that you are online and that the address ends in .csv, .m3u or .m3u8. Playlists on private or local network addresses are blocked on purpose.
The page says progress can't be saved, or the steps reset Private or incognito windows and "clear cookies and site data on exit" erase the saved progress. The steps themselves still work.
