The application is built entirely using HTML, CSS, and JavaScript, allowing it to be hosted on any server of your choice (externally via http:// or https://, or on a local server). With minor adjustments to the JavaScript code, you can also run it directly on your desktop computer. The app features two distinct menus for different purposes: the "Lyric Menu" and the "Prose Menu." The "Lyric/Prose Resource" field is designed to hold a link to an external resource that will open in a new tab. You could by pass the music.html main page to access some specific record, for example, in this way:

http://domain/music.html?source=blues_final.m3u#7 (#7 the record index in the playlist)
Upon loading the page, you will access the server domain, in this case 'https://pretace.surge.sh'. I recommend the surge.sh provider to anyone who decides to have a personal copy of this application to access from anywhere on the Internet (Use Free 'surge' Hosting). As you may have noticed, the page loads a predetermined repertoire contained in a plain text CSV file: "howToUse.csv". The first audio file in that CSV list starts playing immediately or after playing the "Play" button; it's a YouTube video which you can access via a new tab by clicking to the right of the 'URL/file' field. In the field destined to show a lyric by clicking the musical score icon at the end of the field box you can acces the HowToUseThis App page. You can always use this CSV by clicking on 'How To Use this resource (CSV)' in the right-hand column.
You can use a local server, such as the "built-in PHP web server" (ask an AI how to use it). You will be able to access it via your browser's address bar—for example,
http://localhost:8000/book/music.html
However, if you use an online server, such as (the free hosting service "surge"), the address would look something like this: 
https://yourProjectName.surge.sh/book/music.html
In any case, you can always append the specific file you wish to load and play to the URL. For example, the file t1Omaha.csv: 
https://yourProjectName.surge.sh/book/music.html?source=https://yourProjectName.surge.sh/book/t1Omaha.csv a m3u playlist, or a YouTube url
(The browser prevents playback of http://radiostation and requires HTTPS; a message will appear asking whether you wish to play it or cancel to select another station.)

When running the application on localhost, you can access a CSV/m3u file in several ways. You can use "Stop → Load → select the CSV/m3u file → Play" or paste, for example, t1Omaha.csv into the URL/file field and press "Play". You can also enter the full local URL:

http://localhost:8000/book/t1Omaha.csv
(This is usually unnecessary when loading the file directly from the application, since t1Omaha.csv is sufficient, 
but the complete URL can be useful when the CSV/M3U is referenced from another locally hosted page or application.)

The URL/file field can likewise contain a remote URL, for example:
https://yourProjectName.surge.sh/book/t1Omaha.csv
or a YouTube URL. However, a page loaded from a remote server, such as "https://yourProjectName.surge.sh/book/music.html", cannot use the URL or file field to have the remote page fetch a resource from your local server; for example:
http://localhost:8000/book/t1Omaha.csv
This does not make the localhost file available to the remotely hosted application. In that situation, use "Stop → Load →select the CSV/m3u file → Play" to load the local file directly and click "Play".

The "Lyric" field is located below the "URL/file" field. Here, you should enter the "HTML Page url" or any link you wish to open in a new tab when clicking the icon next to the field. It is straightforward and there is not much else to add—much like with the "Author" and "Title" fields—except that all the fields are editable, which makes sense given what we will see later regarding how data is saved to the database.

During playback, clicking the button restarts the current playback and limits the playlist to the single song currently playing.
  • Save: The contents of all fields are saved to the database, but if the checkbox next to the button is not checked, the song and the associated playlist will be saved instead of just the uploaded song.

Creating a CSV Playlist

Use a plain text editor. A CSV "Playlist" file is a collection of lines called records delimited by a vertical bar (|). The first line should be always the following: 
Author|Title|urlFileName|urlLyric

YouTube Playlist: Use a YouTube URL that contains a playlist; for example, "https://www.youtube.com/watch?v=1p_FsT0G5VA&list=PLZWMYVQySf1A&index=1" 

&list=PLZWMYVQySf1A is the playlist, and if the series starts with "RD" the playlist will be not loaded—
you need that the series to start with "PL". Basically, it should be https://www.youtube.com/watch?v=1p_FsT0G5VA

Stop the audio player and paste the YouTube playlist URL into the "Url/field" field; check the "Secondary Playlist" drop-down menu to view the list. Click the "Play" button to load and play it, then click "Export playlist" to download the CSV file.

HowTo download a RD youtube playlist, such us "RDJG6kgKiMbsg":
Use the bash command

yt-dlp --flat-playlist --print "%(id)s|%(title)s|%(webpage_url)s" "https://www.youtube.com/watch?v=JG6kgKiMbsg&list=RDJG6kgKiMbsg&start_radio=1" > rdplaylist.csv

using your https:// url. The playlist will be saved in "rdplaylist.csv". Normalize the content rows using the bash script

./youTube_playLists-v3.scr rdplaylist.csv

for it to become a playable playlist. It will output your updated playlist into the "youtubeOut.csv".

M3U Playlist: The "M3U" file format is more complex than "CSV", but you can convert it to "CSV by using the already known bash script

yt-dlp --flat-playlist --print "%(id)s|%(title)s|%(webpage_url)s" "https://www.youtube.com/watch?v=JG6kgKiMbsg&list=RDJG6kgKiMbsg&start_radio=1" > rdplaylist.csv

Desktop playlist: Use the sequence "Stop → Load → select the CSV/m3u file → Play".
